# 代码地图：讲义章节 ↔ 源码文件

## 对话处理链（从点击发送到气泡）

```text
App.vue sendTextMessage
  → POST /api/chat
  → routers.chat()                    api/routers.py
  → DialogueService.chat()            service/dialogue_service.py
      → _load()                       repository/state_repository.py
      → handle_message(state)         engine/stub_brain.py
          → FlowExecutor.handle()     engine/flow_executor.py
              → _fill_slot / _handle_confirm / _advance
              → ToolRegistry.call()   task/tools.py
                  → 中台 HTTP
      → _append_messages + _save
  → ChatResponse → appendBotMessages  App.vue
```

| 职责 | 文件 | 关键函数 |
|---|---|---|
| HTTP 协议 | `api/routers.py` | `chat` / `history` |
| 出入参 | `api/schemas.py` | `ChatRequest` / `ChatResponse` |
